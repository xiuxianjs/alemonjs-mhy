## 指令一览

### 账号绑定

| 指令                   | 说明                         |
| ---------------------- | ---------------------------- |
| `#绑定ck`              | 绑定米游社Cookie（私聊发送） |
| `#绑定uid`             | 手动绑定游戏UID              |
| `#我的uid`             | 查看已绑定的UID列表          |
| `#我的ck`              | 查看Cookie绑定状态           |
| `#删除ck` / `#删除uid` | 删除Cookie或解除UID绑定      |
| `#ck帮助`              | Cookie获取教程               |
| `#检查ck`              | 验证Cookie是否有效           |
| `#扫码登录`            | 米游社扫码绑定Cookie+Stoken  |
| `#绑定stoken`          | 手动绑定Stoken               |
| `#我的stoken`          | 查看Stoken绑定状态           |
| `#删除stoken`          | 删除已绑定的Stoken           |

### 查询指令

| 指令                        | 说明                 |
| --------------------------- | -------------------- |
| `#体力` / `#树脂`           | 实时树脂/开拓力/电量 |
| `#角色`                     | 角色面板概览         |
| `#深渊` / `#上期深渊`       | 深境螺旋/忘却之庭    |
| `#探索` / `#宝箱`           | 世界探索度           |
| `#武器` / `#五星武器`       | 武器列表             |
| `#邦布`                     | 绝区零邦布列表       |
| `#剧诗`                     | 幻想真境剧诗         |
| `#原石` / `#星琼` / `#札记` | 月收入统计           |
| `#兑换码`                   | 直播兑换码           |
| `#公告` / `#资讯` / `#活动` | 米游社资讯           |

> 以上指令支持游戏前缀：`#原神角色`、`#星铁体力`、`#绝区零体力`
